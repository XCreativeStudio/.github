## 我们相信

**从问题开始，不从点子开始。** 说不清是谁遇到它、他现在怎么凑合，那就还没到写代码的时候。

**做真的有用的事。** 标准不是「有人会点」，是「它做成了，有没有什么东西真的变了」。

**没人看见的活也要做对。** 边界情况、迁移、清理。没人会为此谢你，所以通常被跳过。

**一次做完一件。** 小而完整，好过大而半成品。范围是决定，不是要绕开的限制。

**数据留在用户手里。** 能在浏览器里算完的，就在浏览器里算完。不注册、不上传、不存用不上的东西。

**早点发出去。** 一次发布比一次讨论知道得更多。

## 怎么建

TypeScript · Vue / Nuxt · Node.js · Python。部署在 Vercel，小程序用微信云开发。

代码库要小，技术选型要「无聊」——是故意的。默认开源，除非有明确的理由不开。
