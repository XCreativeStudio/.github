# .github

Organization-wide files for [XCreative Studio](https://github.com/XCreativeStudio). Not a product repo.

- [`profile/README.md`](./profile/README.md) — the introduction shown on the [organization homepage](https://github.com/XCreativeStudio). Push to `main` and the page updates.
- Community health files that apply to every repository in the org (contributing guide, security policy, issue and PR templates) will live here too.

Product code lives in its own repositories — see [all repositories](https://github.com/orgs/XCreativeStudio/repositories).
